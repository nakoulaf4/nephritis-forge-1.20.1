Windows / Forge 1.20.1 / JDK 17

1) Check Java:
   java -version
   Expected major version: 17

2) The project already contains libs/nalim.jar (Nalim v1.1).

3) Start the Forge client with Nalim:
   gradlew.bat runClient

   The run configuration automatically adds JVMCI + -javaagent:libs/nalim.jar.

4) Build the normal mod:
   gradlew.bat build

5) Build Rust native code and then the mod:
   gradlew.bat buildWithNative

   A Windows x64 Rust toolchain with `cargo` is required for the native step.

6) In the startup log, Nephritis should report the Nalim runtime as installed/configured.
   The native backend becomes available only after the corresponding nephritis_native.dll is built and packaged.
